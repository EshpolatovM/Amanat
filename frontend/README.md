# Amanat — frontend

React 18 + Vite ilovasi. O'rnatish va ishga tushirish bo'yicha — [loyiha README](../README.md).

- `src/pages/` — sahifalar (`parent/`, `child/`, `auth/`), `lazyPages.js` orqali alohida bo'laklarga ajratilgan
- `src/components/ui/` — umumiy UI (Button, Modal, ConfirmDialog, holatlar, Toaster)
- `src/components/forms/` — kiritish maydonlari (TextField, SelectField, MoneyField)
- `src/api/` — backend so'rovlari va TanStack Query kalitlari
- `src/lib/` — sana/summa formatlash, validatsiya sxemalari, API klient

Dizayn qoidalari: [`amanat-design-system.md`](../amanat-design-system.md) va `CLAUDE.md` §7.
